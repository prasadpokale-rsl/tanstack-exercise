# Exercise 1: Product List

This exercise uses TanStack Query to get products from the DummyJSON API and show them on the page.

## Features

- Search for products by name.
- Refresh the product list.
- Show loading and error messages.
- Cache results with TanStack Query.

## Run the app

In this folder, run:

```bash
npm install
npm run dev
```

Open the local link shown in the terminal to view the app.
