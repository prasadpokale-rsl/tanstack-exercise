# Exercise 2: User Management

This exercise uses TanStack Query to load and manage users from the DummyJSON API.

## Features

- View a list of users.
- Add a user with a name, email, and role.
- Edit or delete a user.
- See loading, success, and error messages.
- Remove a user from the list immediately when deleting. If the delete fails, the user is added back.

DummyJSON does not keep changes made through its demo API. This app saves successful changes in
the browser so they stay visible when the user list is refreshed.

## Run the app

In this folder, run:

```bash
npm install
npm run dev
```

Open the local link shown in the terminal to view the app.
